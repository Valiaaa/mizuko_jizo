# 鼠标系统

## 为什么不直接切换 CSS `cursor: url(...)`

四张原图的尺寸与长宽比差异很大。浏览器直接替换图片时，缩放规则、热点和显示上限容易造成明显跳位，也无法做短暂的视觉衔接。

当前实现使用跟随系统指针的固定视觉层：

- 真正的点击坐标始终来自系统 Pointer Event，不受图片尺寸影响。
- 每个状态在 `lib/cursor.ts` 单独记录最终显示宽度与热点。
- 所有状态共享同一个定位原点，并用 90ms 透明度交叉切换。
- 按下主按钮时自动进入 Grab，松开后恢复当前区域的状态。
- 触摸屏、粗指针和不支持 hover 的设备不隐藏原生指针。

## 状态

- `normal`：页面普通区域。
- `hand`：按钮、链接、可点击或可拖动物体。
- `grab`：主指针按下期间自动启用。
- `key`：故事中持有或使用钥匙的特殊状态。

## 如何标记区域

```tsx
<button data-cursor="hand">打开</button>
<div data-cursor="key">锁孔</div>
```

按钮和链接即使不写 `data-cursor` 也会自动使用 Hand。特殊故事状态应显式声明。

## 如何微调锚点

只修改 `lib/cursor.ts` 中对应状态的 `hotspot`：

- `x` 增大：图片向左移动，点击点在图片中更靠右。
- `y` 增大：图片向上移动，点击点在图片中更靠下。

热点使用最终 CSS 像素。请在实际页面和最终显示尺寸下微调，不要在各章节中覆盖偏移。
